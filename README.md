# AI Study Assistant

## 🚀 Overview
This project helps students learn topics easily using AI. It generates simple explanations along with quiz questions using prompt engineering techniques.

## ✨ Features
- Generates easy-to-understand notes  
- Creates quiz questions with answers  
- Beginner-friendly explanations  

## 🧠 Prompt Engineering Used
- Role-based prompting  
- Structured output formatting  
- Simplicity-focused responses  

## 🛠 Tech Stack
- Python  
- OpenAI API  

## ▶️ How to Run
1. Install Python  
2. Set your API key:
   export OPENAI_API_KEY=your_key_here  
3. Run:
   python app.py  

## 📌 Example
Input: Topic  
Output: Explanation + Quiz
